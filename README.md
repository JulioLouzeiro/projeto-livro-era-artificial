# 📖 A Era Artificial — Landing Page

Página de divulgação do livro de ficção científica **"A Era Artificial - O Tempo Sombrio das Máquinas"**, criado por Diego Souza. O projeto apresenta a sinopse da obra, informações sobre o autor e links diretos para compra.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das seções (Apresentação, Sinopse, Autor e Chamada para Ação).
* **CSS3:** Estilização em tema escuro (*Dark Mode*), tipografia combinando fontes serifadas e sem serifa, espaçamentos (Box Model) e botões estilizados.

## 🎨 Destaques do Projeto

* Paleta de cores em alto contraste (`#0d0d0d` e `#e8c840`) para reforçar a temática futurista e distópica.
* Uso de seletores CSS básicos e hierarquia tipográfica clara.
* Estrutura organizada em blocos visuais distintos.
